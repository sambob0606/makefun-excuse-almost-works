One line, at most 20 words: the excuse a gamer texts the boss to skip work on GTA 6 launch week. A judge playing a tired manager compares entries two at a time and picks the one it would almost believe; the most believed excuse takes the $2 reward.

The entry line:

> can't come in today, the boiler burst and flooded the kitchen and i'm waiting on the emergency plumber

## Run it

```sh
python3 main.py
```

`main.py` writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (the grader sets it to `/output`; it falls back to `$OUTPUT_PATH`, then `/output`). Stdlib only, deterministic — the same line on every run.
